## 🛠️ Guía rápida de Git

# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/nombre-del-proyecto.git

# 2. Entrar a la carpeta
cd nombre-del-proyecto

# 3. Crear tu rama de trabajo (USA TU NOMBRE)
git checkout -b feature/tu-nombre-seccion

# 1. Actualizar tu repositorio local
git pull origin main

# 2. Ver en qué rama estás (debe ser tu rama personal)
git branch

# 3. Trabajar en tus archivos (DENTRO de tu carpeta asignada)

# 4. Preparar cambios
git add tu-carpeta-asignada/

# 5. Guardar cambios con mensaje descriptivo
git commit -m "feat: agrega [lo que hiciste] - [tu nombre]"

# 6. Subir cambios
git push origin feature/tu-nombre-seccion
